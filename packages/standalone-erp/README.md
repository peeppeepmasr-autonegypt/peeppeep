# 🚗 منظومة مستشارك — Mostasharak

**المنظومة السحابية والمحلية المتكاملة لإدارة معارض السيارات، الحسابات المالية العامة، الأقساط، وسوق البيع المباشر (Accounting ERP & Marketplace)**

---

## 🌟 نبذة عن المنظومة
**مستشارك (Mostasharak)** هو نظام متكامل مصمم خصيصاً لتلبية احتياجات أصحاب معارض السيارات وتجار المركبات في السوق المصري والعربي.  
يعمل النظام بنمطين متكاملين: **النمط المستقل (Standalone)** بدون أي سيرفر وبدون إنترنت، أو **النمط المتصل والمزامن (Connected)** عبر الشبكة المحلية (Wi-Fi) أو السحابة المركزية (Google Sheets API).

---

## 📂 الهيكل والملفات الرئيسية (Core Files)

| الملف | الوصف |
| :--- | :--- |
| **`install.html`** | **معالج التثبيت والتشغيل الذكي:** يتعرف تلقائياً على نوع الجهاز (كمبيوتر ويندوز أو هاتف محمول أندرويد/آيفون) ويوفر خيار تثبيت المحاسبة، السوق، أو الاثنين معاً مع زر التثبيت كتطبيق أصلي (PWA). |
| **`mostasharak-accounting.html`** | **نظام المحاسبة والإدارة المالية (القسم الخاص):** جرد المخزون، الشراء والتوريد، قيود اليومية المزدوجة الآلية، الأستاذ العام، إدارة العقود والتحصيل، وميزان المراجعة، مع كتالوج الاستخدام ودليل المزايا المدمج في تبويب الإعدادات. |
| **`mostasharak-market.html`** | **تطبيق سوق ومعرض السيارات (القسم العام):** كتالوج السيارات والمركبات، حاسبة تمويل البنوك المصرية (الأهلي، مصر، CIB، QNB)، توليد كروت واتساب عالية الدقة (📸 كارت صورة)، وشريط الإعلانات والتنبيهات المجدول. |
| **`Setup-Mostasharak.bat`** | **مثبت ويندوز التلقائي:** تشغيل فوري لكلا النظامين، وإنشاء اختصارات رسمية على سطح مكتب ويندوز بنقرة واحدة. |
| **`MOSTASHARAK_ACCOUNTING_MANUAL_AR.html`** | **دليل المحاسبة والتوجيه المالي:** شرح مبسط مع 5 أمثلة عملية من واقع معارض السيارات (شراء، بيع، سيارات أمانة ووساطة، تحصيل أقساط، وميزان مراجعة). |
| **`serve.js`** | خادم Node.js محلي خفيف لربط طلبات السوق (`/api/orders`) وبث شريط التنبيهات (`/api/ribbons`). |
| **`Code.gs`** | محرك Google Apps Script متعدد المستأجرين لعزل بيانات كل معرض وإدارة التراخيص السحابية. |

## 🚀 المميزات الرئيسية
1. **معمارية العمل المزدوجة (Dual-Mode):**
   - **أوفلاين مستقل (Standalone):** يعمل كل ملف كصفحة ويب مستقلة 100% تحفظ بياناتها في ذاكرة المتصفح، مع مزامنة لحظية بين التبويبات عبر تقنية `BroadcastChannel`.
   - **متصل ومزامن (Connected):** ربط أجهزة المعرض عبر الشبكة المحلية أو السحابة المركزية.
2. **شريط السوق المجدول (Mostasharak Ribbon):**
   - بث رسائل مؤقتة (من تاريخ ووقت إلى تاريخ ووقت).
   - استهداف عام أو خاص برقم هاتف عميل محدد.
   - دعم روابط الكلمات التشعبية `[نص الرابط](رابط)` وتصنيفات (أخبار 📢 / إشعارات 🔔 / تحذيرات ⚠️).
3. **فصل حسابات سيارات الأمانة لحماية رأس المال:**
   - عدم لمس مخزون المعرض، وقيد العمولة فقط كإيراد صافٍ، وإثبات حق المالك الخارجي كالتزام أمانة.
4. **توليد كروت واتساب الذكية:**
   - كروت صور عالية الدقة (PNG) مجهزة للمشاركة على حالات ومجموعات الواتساب بضغطة زر.
5. **توافق متعدد المنصات (Cross-Platform PWA):**
   - يعمل على Windows, macOS, Android, iOS.
